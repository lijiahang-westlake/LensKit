镜头调色

实时滤镜取景 + 运镜录影 + 一键出片模板
适配小米 17 Max / 全系 Android（10.0+）

下载 Android 版（APK） 直接打开网页版（免安装）

安装步骤

  1. 手机浏览器打开本页，点「下载 Android 版」
  2. 下载完成后点开 APK，系统提示「未知应用」时选择允许
  3. 首次打开会请求相机权限（用到收音时再请求麦克风），同意即可取景

安装时若出现「有风险」提示，是因为 APK 为自签名发布（未上架商店），确认来源后点「仍要安装」即可。

功能

  • 调色：10 款预设 + 十余项手动调节 + 自定义预设（磨皮 / 颗粒 / 暗角 / 胶片感…）
  • 一键出片：6 个「滤镜 + 多段运镜」组合模板，选一个直接录成片
  • 运镜：15 个模板（推近 / 环绕 / 甩镜 / 希区柯克变焦 / 手持感…），3–15 秒可调
  • 视频：照片 / 视频双模式，运镜往返循环，可收音，最长 5 分钟
  • 构图提示：主体位置、三分交点、地平线倾角 + 构图评分
  • AI 场景：本地识别夜景 / 美食 / 人像 / 风景 / 逆光 / 雪景，并按画面微调模板
  • 进阶：光轨长曝光、延时摄影、专业参数（ISO / 色温 / 对焦…）、连拍、定时、网格、水平仪、画幅比例、日期水印
隐私说明：App 不含任何网络统计/上报代码，唯一网络权限仅用于本机内部通信（127.0.0.1），照片和视频不会离开手机。
